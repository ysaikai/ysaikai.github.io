How to use Gardening Assistant

This app helps you keep records and offers personalized suggestions for everyday gardening activities.

Suggestions

Suggestions are made based on data you provide (and local weather data). As always, you get out what you put in. For example, when a suggestion is unhelpful (e.g. impractical, generic, or inaccurate), writing concise comments in relevant activity or observation records can significantly improve its quality.

Siri

A useful way to use Siri for this app is to start a follow-up discussion about a suggestion. Suppose you wonder whether it is good. You can bring it onto the screen and ask Siri, “What do you think about this suggestion based on the note attached here?” A key is to include indicative words like “this” and “here” so that Siri can be aware that you are referring to the on-screen contents. A note is invisible but attached to the screen where a target is uniquely specified (i.e. Suggestions, Suggestion, and Observation). It is target-specific, containing activity history, observation history, and recent weather history as background information for Siri.

Targets

A target is a unit of management activities and observations. It can be a single plant (e.g. tomato plant) or a collection of plants (e.g. a spinach patch). Most features of the app are centered around targets — an observation is recorded for a target, an activity is recorded for a set of targets, and a suggestion is made for a target. For example, if you want to keep separate sets of data for tomato plants in a garden, you create multiple targets for the same plant type (tomato). When creating a target, you are required to enter a name and a plant type. It is probably a good idea to use a common variety name because the model may recognize the name and find pertinent information about it. To avoid unnecessary confusion, a plant type should be a common category such as tomato, lettuce, and onion.

Profile

Data in the profile is used for each target when getting suggestions. For example, location is used to obtain relevant weather data. Soil texture, bed type, and gardening style are there only because of developer's limited experience. Please make use of Notes boxes at the bottom of Profile to personalize suggestions. Targets and the profile have common items such as location. If you fill out them in both, ones in targets are used.

iCloud sync

By default, data you enter is uploaded to iCloud and synced across all devices. Keep in mind that sync is not instantaneous, and you may create, update, or delete data offline. Most of the time, sync works as you expect: distinct records coexist, and if you edit a unique record from multiple devices, the last edit wins.

If you manually turn off iCloud sync for the app, all synced data will disappear from the device. Once you turn it back on, the data will reappear. While the data is disappearing, it is easy to create conflicts for items you edit in the menu (i.e. Targets, Inputs, etc.). So do not touch them if you plan to turn syncing back on. If you want a clean slate, you should first delete the app's data from iCloud.
